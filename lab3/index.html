Lab 3: Web Data Acquisition: Met Ceramics

Dataset: Ceramic objects in the Metropolitan Museum of Art collection
Source: The Met Collection API (collectionapi.metmuseum.org) which is open for public use
Method: API requests using Python and the requests library. I made 6 searches (porcelain, stoneware, earthenware, terracotta, celadon, glazed ceramic) and filtered to the Ceramics medium, which returned object IDs and then for each object, I requested for its attributes. I took and renamed 6 of the 12 attributes, the ones that were most useful to a user.
